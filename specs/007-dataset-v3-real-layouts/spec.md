## Clarifications (2026-11-05)
- 200 generated CVs: junior 50, middle 60, senior 60, lead/architect 30.
- Generated CVs mostly in English (~85 %), the rest Vietnamese.
- Real test set: 20 real CVs never used for training; Claude drafts gold labels, the user reviews them.
- Real CVs are not sent to Gemini/ChatGPT; only fictional profiles are generated by subagents.

## User Scenarios

### US1 — Locked real test set (P1)
20 real CVs that are in no training data (any similarity > 70 % to train excluded), diverse layouts, PDFBox text, gold drafted by Claude and reviewed by the user. Stored only under git-ignored `ai-service/data/`.

### US2 — Real CVs for training with aligned labels (P1)
Remaining real CVs with older labels: every label value is snapped to the PDFBox text (fuzzy ≥ 85 → exact span), ungrounded values dropped, v3 conventions applied. No manual labelling.

### US3 — 200 generated CVs in real layouts (P1)
Fictional structured profiles (subagents) → 8–10 HTML layout templates modelled on the real CVs → PDF (LibreOffice) → text via the backend PDFBox endpoint. The label is the profile itself, kept only where the value is found verbatim in the extracted text.

### US4 — Dataset v3 + prompt v3 (P1)
Builder merges generated (200), aligned real (~33, oversampled ×3 with entity swap) and a subset of old synthetic CVs; prompt v3 states the v3 conventions; the train notebook takes `RUN_NAME="v3"`.

## Label conventions v3
- Every value copied verbatim from the CV text (PDFBox), never normalised.
- `languages`: spoken languages only. Programming languages always go to `skills`, even under a "Languages:" sub-heading.
- `skills`: one item per skill; group labels ("Backend:", "ORM:") removed; items from all skill sub-groups.
- `experience.company`: organisation name only (no location, date or title on the same line).
- `end_date`: null when the CV says Present / Now / Hiện tại.
- `start_year`, `end_year`, `team_size`: integers; other scalars strings.
- `personal_projects.description`: list of verbatim bullets; `tech_stack`: items only, group labels removed.

## Success Criteria
- SC-001: On the 20-CV real test set, v3 beats v2 on every field (variant B), and company, school, skills ≥ 0.85.
- SC-002: No regression > 2 points on the synthetic val set.
- SC-003: 0 generated labels with values absent from their PDFBox text.
- SC-004: Generated CVs cover all 4 levels in the requested counts and ≥ 8 layouts.

## Assumptions
- Image CVs (30) and scanned PDFs (2) need OCR; out of scope for v3 training, candidates for a later OCR test set.
- Generated profiles are fictional; company names may be real employers, person names / contacts are invented (valid VN phone format, 10 digits).
