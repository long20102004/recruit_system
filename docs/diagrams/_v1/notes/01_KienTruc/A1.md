# A1 — Kiến trúc hệ thống theo chiều dọc (Microservices)

## 1. Lý do xếp loại kiến trúc "Microservices" và Dẫn chứng từ mã nguồn

Căn cứ theo mục 1.1 của [DIAGRAM_RULES.md](../../DIAGRAM_RULES.md), hệ thống **HireLens** được phân loại chính xác là kiến trúc **Microservices** dựa trên 4 đặc trưng kiến trúc thực tế trong source code và cấu hình triển khai:

1. **Triển khai độc lập (Independent Services & Containers):**
   - Hệ thống không phải là một khối đơn nhất mà được module hóa thành các tiến trình riêng biệt, đóng gói container Docker độc lập với cấu hình môi trường và cổng mạng riêng (`source/recruit_system/docker-compose.yml:1-256`):
     - Web Client: React SPA chạy trên cổng `5173` (`source/recruit_system/frontend/vite.config.ts:7`).
     - API Gateway: Nginx reverse proxy chạy trên cổng `8080` (`source/recruit_system/infra/gateway/nginx.conf:2`).
     - `identity-service`: Spring Boot chạy trên cổng `8081` (`source/recruit_system/backend/identity-service/src/main/resources/application.yml:2`).
     - `recruitment-service`: Spring Boot chạy trên cổng `8082` (`source/recruit_system/backend/recruitment-service/src/main/resources/application.yml:2`).
     - `interview-service`: Spring Boot chạy trên cổng `8083` (`source/recruit_system/backend/interview-service/src/main/resources/application.yml:2`).
     - `interview-ai`: FastAPI chạy trên cổng `8000` (`source/recruit_system/docker-compose.yml:229`).
     - `cv-extraction-ai`: FastAPI chạy trên cổng container `8000`, ánh xạ cổng host `8001` (`source/recruit_system/docker-compose.yml:242`).
     - `cv-matching-ai`: FastAPI chạy trên cổng container `8000`, ánh xạ cổng host `8002` (`source/recruit_system/docker-compose.yml:255`).

2. **Cơ sở dữ liệu phân tán riêng biệt (Database-per-Service):**
   - Không tồn tại cơ sở dữ liệu dùng chung. Mỗi dịch vụ Spring Boot sở hữu một instance CSDL MySQL 8.4 độc lập với chuỗi quản lý phiên bản Flyway riêng biệt:
     - `identity-service` kết nối `hirelens_identity` (port 3307/3306) (`source/recruit_system/docker-compose.yml:25`, `source/recruit_system/backend/identity-service/src/main/resources/application.yml:7`).
     - `recruitment-service` kết nối `hirelens_recruitment` (port 3308/3306) (`source/recruit_system/docker-compose.yml:43`, `source/recruit_system/backend/recruitment-service/src/main/resources/application.yml:7`).
     - `interview-service` kết nối `hirelens_interview` (port 3309/3306) (`source/recruit_system/docker-compose.yml:61`, `source/recruit_system/backend/interview-service/src/main/resources/application.yml:7`).
   - Tuyệt đối không có ràng buộc khóa ngoại (Foreign Key) vật lý xuyên cơ sở dữ liệu; quan hệ giữa các bảng khác service là quan hệ logic qua ID (`source/recruit_system/docs/schema.dbml:3`).

3. **Cổng giao tiếp duy nhất qua API Gateway (Single Entry Point):**
   - API Gateway Nginx (`infra/gateway/nginx.conf`) tiếp nhận mọi request từ Frontend tại cổng `8080`, định tuyến theo path prefix tới đúng service nội bộ:
     - `/api/auth/**` → `identity-service:8081` (`source/recruit_system/infra/gateway/nginx.conf:15-18`)
     - `/api/interviews/**` → `interview-service:8083` (`source/recruit_system/infra/gateway/nginx.conf:19-22`)
     - `/api/(jobs|cvs|applications|matching|dashboard)/**` → `recruitment-service:8082` (`source/recruit_system/infra/gateway/nginx.conf:23-26`)
   - Nginx thiết lập hàng rào bảo mật chặn đứng mọi truy cập trực tiếp từ bên ngoài vào API nội bộ: `location ~ ^/internal(?:/|$) { return 404; }` (`source/recruit_system/infra/gateway/nginx.conf:14`).

4. **Giao tiếp liên dịch vụ qua mạng và bảo mật Service Token:**
   - Các service không truy cập dữ liệu của nhau trực tiếp mà tương tác qua HTTP REST trên các endpoint `/internal/*`.
   - Tất cả request nội bộ đều bắt buộc có header `X-Service-Token` và được xác thực qua filter `InternalAccessFilter` (`source/recruit_system/backend/common/src/main/java/recruit/demo/security/InternalAccessFilter.java:22-26`).
   - Dẫn chứng luồng gọi liên service:
     - `RemotePrincipalLookup` trong `common` gọi `identity-service` tại `GET /internal/users/{id}` để xác minh token người dùng (`source/recruit_system/backend/common/src/main/java/recruit/demo/security/RemotePrincipalLookup.java:19`).
     - `InterviewService` gọi `recruitment-service` tại `GET /internal/interview-context` để lấy ngữ cảnh ứng viên và tin tuyển dụng khi bắt đầu phỏng vấn (`source/recruit_system/backend/interview-service/src/main/java/recruit/demo/service/InterviewService.java:48`).
     - `DashboardService` trong `recruitment-service` gọi `interview-service` tại `GET /internal/interviews/question-count` để thống kê số lượng câu hỏi phỏng vấn (`source/recruit_system/backend/recruitment-service/src/main/java/recruit/demo/service/DashboardService.java:31`).
   - Tương tác với các dịch vụ AI hoàn toàn qua giao thức HTTP JSON chuyên biệt:
     - `CvExtractionModule` gọi `cv-extraction-ai` tại `POST /api/v1/extract-cv?include=kg` (`source/recruit_system/backend/recruitment-service/src/main/java/recruit/demo/service/cv/CvExtractionModule.java:24`).
     - `CvMatchingModule` gọi `cv-matching-ai` tại `POST /match/no-llm` (`source/recruit_system/backend/recruitment-service/src/main/java/recruit/demo/service/matching/CvMatchingModule.java:18`).
     - `AiScoringClient` gọi `interview-ai` tại `POST /v1/interview/evaluate` (`source/recruit_system/backend/interview-service/src/main/java/recruit/demo/service/AiScoringClient.java:86`).

## 2. Mâu thuẫn giữa Tài liệu và Mã nguồn (Source Code)

| Hạng mục | Tài liệu đồ án cũ (bản báo cáo v6) | Mã nguồn thực tế (`commit 1c96706`) | Ghi chú xử lý |
|---|---|---|---|
| **Mô hình kiến trúc tổng thể** | Mô tả hệ thống nguyên khối (Monolith) với một backend Spring Boot duy nhất quản lý toàn bộ nghiệp vụ. | Đã chuyển đổi hoàn chỉnh sang kiến trúc **Microservices** phân tán với 3 backend Spring Boot độc lập, API Gateway Nginx, 3 CSDL MySQL độc lập và 3 dịch vụ AI FastAPI. | Người dùng đã chốt vẽ chuẩn hóa theo **Mã nguồn thực tế**. |
| **Cơ sở dữ liệu** | Sử dụng một cơ sở dữ liệu MySQL duy nhất `recruit_system`. | Tách thành 3 CSDL riêng biệt: `hirelens_identity`, `hirelens_recruitment`, `hirelens_interview`. CSDL cũ `recruit_system` chỉ còn nằm ở Docker profile `legacy` phục vụ xuất dữ liệu cũ (`export-legacy.py`). | Vẽ 3 database riêng theo từng service; không vẽ CSDL cũ vào kiến trúc runtime. |
| **Thư viện dùng chung (`common`)** | Báo cáo cũ chưa có khái niệm module `common`. | `backend/common` được tổ chức thành thư viện mã nguồn dùng chung compile-time (chứa DTO, JWT auth, filter bảo mật token nội bộ, HTTP client); không có database và không chạy runtime độc lập. | Không vẽ `common` thành một component runtime độc lập mà là thư viện nhúng trong 3 Spring services. |
| **Dịch vụ AI** | Chỉ đề cập lý thuyết hoặc hàm xử lý nhúng. | Tách thành 3 microservice AI FastAPI (Python 3.11) riêng biệt đóng gói trong Docker: trích xuất CV (Qwen GGUF v4 + KG), đối sánh CV-JD (Sentence Transformers) và chấm điểm phỏng vấn (BERTScore + Ridge). | Thể hiện đầy đủ 3 AI components và các volume chứa mô hình tương ứng. |
