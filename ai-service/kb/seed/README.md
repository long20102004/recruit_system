## Universities are an open set

Like companies, schools are not validated against the KB: grounding (the name must appear in the CV) is the check. The university tables only normalise spellings (Vietnamese / English / abbreviation) to one entry. Schools absent from the list stay valid; abbreviations shared by several schools (e.g. "DTU") and member-school names without their parent university are deliberately not used as aliases.
