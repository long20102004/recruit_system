# HireLens — bản giao diện tĩnh

Bản HTML tĩnh dùng ở giai đoạn thiết kế giao diện. Không nối backend.

## Vai trò

### Ứng viên

1. Xem và tìm việc
2. Tải CV, kiểm tra thông tin, xác nhận hồ sơ
3. Xem việc phù hợp
4. Ôn tập phỏng vấn văn bản

### Nhà tuyển dụng

1. Đăng vị trí tuyển dụng
2. Quản lý tin đang mở
3. Xem hồ sơ ứng viên
4. Ghép hồ sơ với tin tuyển dụng
5. Ngân hàng câu hỏi và kết quả phiên phỏng vấn

## Cách mở

```bash
cd ui-prototype
python3 -m http.server 5500
```

Mở `http://localhost:5500`.

Bản giao diện đang chạy của hệ thống nằm ở thư mục `frontend/`.
